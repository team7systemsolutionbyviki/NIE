ESP32 DevKit V1 Wearable Hardware Interfacing & Wiring Diagram Hardware Pinout

This circuit interfaces two MPU-6050 6-DOF IMUs over a shared I2C bus (distinguished by the AD0 address pin), one FSR force-sensitive resistor via a voltage divider to an analog ADC pin, and one DS18B20 digital temperature probe via Dallas OneWire.

Key Hardware Assembly Details:

  • How Dual IMUs Share Pins: Both MPU-6050 sensors connect to the exact same I2C lines (GPIO 21 SDA and GPIO 22 SCL). Setting AD0 → GND sets the Thigh sensor to address 0x68, while setting AD0 → 3.3V switches the Lower-leg sensor to 0x69.
  • FSR Resistor (10kΩ): Forms a voltage divider so the ESP32 ADC on GPIO 34 reads between 0V (no touch) up to ~3.3V (firm pressure).
  • DS18B20 Resistor (4.7kΩ): Connected between 3.3V and the OneWire Data line (GPIO 4) to ensure proper digital bus communication.
  • Firmware Sketch: The matching Arduino sketch is in firmware/esp32_knee_ble.ino.
SQLite WASM Browser Database Architecture Local Persistence Active

This application compiles the official SQLite relational engine to WebAssembly (WASM) and executes it entirely client-side. All session metadata, 6-DOF sensor packets, body temperatures, calibration profiles, and AI predictions are written to SQLite tables and mirrored to the browser's IndexedDB binary storage.

Browser persistent storage belongs strictly to this website origin (GitHub Pages URL) and current browser profile. Clearing your browser cache or switching devices will not automatically sync records. Use the backup tools below to save copies.
